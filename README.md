# DawgSkins (Work in progress)

## Description
This is a project for tracking price changes of skin CS2. You can add the items you're interested in your favorites and monitor their price changes in real time.

## Technologies
* TypeScript
* HTML5
* CSS3
* Vite

## Tools
* Figma (Layout)
* Git (Version control)
* Claude, DeepSeek (Ai assistants)
* Storybook

## Libraries
* React
* Lucide-React

## API
* CS2Cap (Free plan)

## Main page

This is the main page of the project. It display a grid of skins, a filter panel and a "Header" component with items search functionality
